「オリパスタジアムって新しいアプリだけど大丈夫？」「キャッシュバックが太っ腹すぎて逆に怪しい」——聞き慣れないアプリほど、先に調べておくのは正しい判断です。

私はこの3年で24個のオリパアプリに自腹で課金し、検証に使った金額は累計約912万円。オリパスタジアム（通称オリスタ）は2026年2月リリースとこの6アプリで最も新しいアプリですが、私はおすすめランキングで3位に置いています。

この記事では、SNSに上がっている評判の実態、オリスタ最大の武器である毎週キャッシュバックの仕組み、そして新しいアプリゆえの注意点まで書きます。

結論：オリパスタジアムの評判と向き不向き

評判を4行にまとめると

  • 還元の手厚さは6アプリでも上位 — 毎週水曜に購入コインの最大10%が戻るキャッシュバックがあります
  • 送料が原則無料 — 6アプリの中で送料の負担が最も軽いアプリのひとつです
  • 「発送が遅い」という声には幅がある — 私の実測は3日でしたが、1週間かかったという報告も見かけます
  • ポケカ特化なので遊びの幅は狭い — ワンピや遊戯王を回したい人には向きません

「怪しい」で言えば、株式会社ミックスによる法人運営で古物商許可も取得済みです。運営面で不透明な点は見当たりません。ただしリリースから日が浅いぶん、長期の実績はこれから積み上がる段階です。

オリパスタジアムが向いている人・向いていない人

向いている人

  • ポケカだけを回したい
  • こまめに少額ずつ発送したい（送料が原則無料）
  • ある程度まとまった額を回す予定がある（キャッシュバックが効く）
  • 決済手段の選択肢が多いほうがいい

向いていない人

  • ワンピース・遊戯王など他ジャンルも回したい
  • 運営実績の長さを重視する
  • 発送を急いでいる（繁忙期に遅れる報告あり）

他アプリとの横並びはオリパアプリ徹底比較にまとめました。

オリパスタジアムの良い評判・口コミ

PSA10やプロモカードの当選報告が上がっている

リリースから日が浅いアプリですが、当選報告は継続的に上がっています。

「25周年プロモが当たった」といった報告がXに上がっています。リリースから日が浅いアプリですが、当選報告が公式のキャンペーン投稿だけで埋まっていない点は、選び方の5条件の条件1をクリアしています。

梱包が丁寧

スリーブ＋ローダー＋防水対策という梱包で届くという声が多く見られます。当たったカードの価値は状態で決まるので、ここが雑なアプリは実質的に損をします。オリスタはこの点で評価が安定しています。

送料が原則無料

6アプリの中で送料負担が最も軽い部類です。ビクトレの一律500円と比べると、こまめに発送する使い方での差は決定的になります。

小口で引いて、当たったらすぐ発送したいタイプの人には、この一点だけでも選ぶ理由になります。

決済手段が幅広い

クレカ・ApplePay・GooglePay・AmazonPay・メルペイに加えて、あと払い（ペイディ・atone・コンビニ）にも対応しています。支払い方法で詰まりにくいのは地味ですが効く長所です。

オリパスタジアムの悪い評判・口コミ

「1週間経っても発送されない」という声

ここは評判が割れています。私の実測は3日でしたが、「1週間経っても発送されない」という報告も見かけます。

キャンペーン直後や連休は発送が混み合うので、急いでいるときに使うアプリではないというのが正確な理解です。時期によって体験が変わる項目なので、口コミの投稿時期も見てください。

「課金しても当たらない」という声

「5万円課金しても当たらない」という声もあります。確率商品である以上どのアプリでも出る評判ですが、無視していい話でもありません。

私の見方はオリくじの記事にも書いたとおりで、還元率を確認せずに引くと体感はそうなります。オリスタには総還元率100%超のオリパがあるので、引く前にそこを見るだけで結果の傾向は変わります。

ポケカ特化で遊びの幅が狭い

ポケカ専門です。ワンピース・遊戯王・ガンダムは扱っていません。

これは弱点であると同時に、ポケカに在庫を集中できるという意味では設計の一貫性でもあります。ポケカだけ回す人にとっては、むしろ有利に働きます。

運営実績がまだ短い

2026年2月リリースで、この6アプリの中では最も新しいアプリです。法人運営で古物商許可も取得していますが、「何年も続いている」という種類の安心感はまだありません。

長期の運営実績を重視する人は、東証スタンダード上場グループの連結子会社が運営するビクトレのほうが条件に合います。

オリパスタジアムのキャッシュバックと還元の仕組み

毎週水曜のキャッシュバック祭

オリスタ最大の武器がこれです。毎週水曜、購入コインの最大10%が会員ランクに応じて戻ります。

重要なのは、これが「当たったら戻る」ではなく買った額に対して戻るタイプの還元だという点です。当たり外れに関係なく、使った分の一定割合が確定で戻ってきます。

そのため回す量が多いほど効きます。月に数千円だけ遊ぶ人より、まとまった額を回す人のほうが恩恵は大きくなります。逆に少額で楽しむ人には、オリくじの逆転コインのような「外した分が残る」タイプのほうが体感の満足度は高いはずです。

きゅるるんループと総還元率100%超オリパ

ガチャ設計としては、1/1.4の「きゅるるんループ」と総還元率100%超のオリパがあります。

1/1.4はかなり高い当選確率です。確率が読めるガチャは「いくらまで出すか」を決めやすいので、選び方の条件4で私が重視している「口数の少ないガチャ・確率の読めるガチャ」に該当します。

オリスタ祭とミステリーガチャ

毎月10日の「オリスタ祭」、そして中身が伏せられた「ミステリーガチャ」など、イベント性の高い企画が定期的に走ります。

毎週水曜と毎月10日という決まったサイクルがあるので、タイミングを合わせて回すだけで条件が良くなるアプリです。思い立ったときに引くより、水曜と10日を狙うほうが有利になります。

この「決まった日にイベントがある」設計は、実は使いすぎの抑制にもなります。いつでも同じ条件なら際限なく引けてしまいますが、条件が良い日が決まっていれば、そこまで待つという判断ができます。予算を守りたい人には、この点も相性が良いはずです。

会員ランク特典との組み合わせ

キャッシュバックの率は会員ランクに応じて変わります。上位ランクほど戻る割合が大きくなる仕組みです。

ここで注意したいのは、オリくじのランク制度と同様、ランクを維持するには継続的な利用が前提になるという点です。無理にランクを追いかけると、還元のために課金するという本末転倒な状態になります。私は「自然に上がった分だけ恩恵を受ける」くらいの距離感が健全だと思っています。

私が実際に引いて確かめた3つのこと

評判を並べるだけでは意味がないので、自分で確かめた項目を書いておきます。

1. 発送は何日かかったか

私の実測では3日で到着しました。梱包はスリーブとローダーで保護され、防水対策もされた状態です。ただし前述のとおり1週間かかったという報告もあるので、私の3日を「常にこうなる」と受け取らないでください。

2. 送料が本当に無料か

原則無料であることを確認しました。ビクトレで送料500円を払っていた身からすると、こまめに発送できる自由度はかなり大きい違いです。少額で回して当たったらすぐ送る、という使い方が成立します。

3. キャッシュバックが実際に戻るか

毎週水曜に、購入コインに対する還元が入ることを確認しました。会員ランクによって率が変わるので、自分のランクでいくら戻るかはアプリ内の表示で確認してください。

※上記は筆者が試した時点の結果であり、発送日数は繁忙期に延びる場合があります。キャッシュバックの率や条件は変更される可能性があるため、アプリ内の最新表示をご確認ください。

筆者ユウジ

オリスタは「サイクルに合わせて使うアプリ」だと私は捉えています。毎週水曜と毎月10日という決まった日があるので、そこに合わせて回すだけで条件が変わる。思いつきで引くのがいちばんもったいないタイプです。逆に言えば、予定を立てて遊べる人には向いているアプリです。

オリパスタジアムは怪しいのか（安全性の検証）

結論から言えば、運営面で怪しい要素は見当たりません。

  • 株式会社ミックスによる法人運営
  • 古物商許可番号を取得済み
  • 決済手段が幅広く、大手決済事業者が入っている

秋葉原の実店舗を持つカードショップが運営するメディアも、法人運営で古物商許可があるという点から安全と評価しています。

「怪しい」と言われる要因は、おそらくキャッシュバックが太っ腹すぎることとリリースから日が浅いことの2つです。ただし新規ユーザー獲得のために還元を厚くするのは、この業界では珍しくない立ち上げ戦略です。私が危険と判断する条件は「還元率表示は派手なのに運営情報が薄い」パターンですが、オリスタは運営情報を出している側にあります。

そのうえで、運営実績の長さという意味ではまだこれからというのは事実です。ここを重く見るかどうかは、読む人の判断になります。

筆者おすすめのオリパスタジアムのオリパ

オリスタは引く枠より「引く日」で条件が変わるアプリです。そのうえで見るべき枠を挙げます。

1. 新規限定のアド確ガチャ7種

登録直後にだけ出る時間限定の枠で、7種類用意されています。常設より条件がいいので、まずここから。時間限定なので、登録して放置すると消えます。

2. 総還元率100%超オリパ

還元率が明記されている枠です。選び方の条件2で書いたとおり、還元率は引く前に確認できる数少ない判断材料なので、ここを見ずに引くのはもったいないです。

3. きゅるるんループ（1/1.4）

当選確率1/1.4という高確率の枠です。確率が読めるぶん予算を立てやすく、少額から試したいときの入口として使えます。

4. 水曜のキャッシュバック祭に合わせて引く

枠の話ではありませんが、これが実質いちばん効きます。同じガチャでも水曜に引けば購入コインの最大10%が戻ります。毎月10日の「オリスタ祭」も同様です。思いつきで引くより、この2つの日に合わせるだけで条件が変わります。

オリパスタジアムの登録手順と特典

オリパスタジアムに招待コードはありません。 コードの入力欄を探しても見つからないのが正常なので、探す必要はありません。

代わりに押さえるべき特典が2つあります。

  1. アプリをインストール、または公式サイトを開く
  2. 新規会員登録を済ませる
  3. ガチャ一覧の「新規向け」を開く — 新規限定のアド確ガチャ7種（時間限定）が出ています
  4. LINE連携を済ませる — 連携者限定のコイン増量クーポンがあります（最大50,000pt獲得可能）
  5. 水曜まで待てるなら、キャッシュバック祭に合わせて課金する

新規限定ガチャは時間限定なので、時間が取れるタイミングで登録するのがおすすめです。他アプリの招待コードはオリパ招待コード一覧にまとめています。

オリパスタジアムの評判に関するよくある質問

オリパスタジアムに招待コードはありますか？

ありません。コードの入力は不要です。代わりにLINE連携者限定のコイン増量クーポンがあるので、登録後にLINE連携をしておくと取りこぼしがありません。

発送はどれくらいかかりますか？

私の実測では3日でした。ただし1週間かかったという報告もあり、繁忙期は延びる可能性があります。急ぎの用途には向きません。

送料はかかりますか？

原則無料です。6アプリの中でも送料負担が最も軽い部類で、こまめに発送したい人に向いています。

キャッシュバックはいつもらえますか？

毎週水曜です。購入コインの最大10%が会員ランクに応じて戻ります。当たり外れとは関係なく、買った額に対して戻る仕組みです。

ポケカ以外も引けますか？

引けません。ポケカ特化のアプリです。ワンピースや遊戯王も回したい人は、対応ジャンルの広いオリくじのほうが合います。

新しいアプリですが安全ですか？

株式会社ミックスによる法人運営で、古物商許可番号も取得しています。運営情報の面では問題ありませんが、長期の運営実績という意味ではまだこれからの段階です。

オリパスタジアムの評判まとめ

良い点 — 毎週水曜に購入コインの最大10%が戻るキャッシュバック／送料が原則無料／総還元率100%超オリパと1/1.4のきゅるるんループ／梱包が丁寧／決済手段が幅広い／新規限定アド確ガチャ7種とLINEクーポン

注意点 — 発送が1週間かかったという報告もある／ポケカ特化で遊びの幅は狭い／2026年2月リリースで運営実績はまだ短い

「怪しい」という評判については、法人運営で古物商許可もあり、根拠のある指摘とは言えないというのが私の結論です。手厚いキャッシュバックは立ち上げ期の新規獲得戦略として自然なもので、そこを不審に思う必要はないと考えています。

ポケカだけを回すなら、送料無料とキャッシュバックの組み合わせは相当に強いです。まずは新規限定ガチャとLINEクーポンを押さえたうえで、水曜に合わせて試してみてください。
